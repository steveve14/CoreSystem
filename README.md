# 나만의 가계 부
회원가입/로그인  (간단한 아이디 비밀번호 기반 로그인),
가계부 항목 등록 (날짜, 항목명, 수입/지출, 금액 메모입력),
가계부 목록 보기 (테이블 형태로 입력된 항목 나열),
항목 수정/삭제  (해당 월 또는 전체 기간의 수입/지출/잔액 표시),
검색/필터       (월별/ 수입 지출별 검색 기능),

# 추가기능
카데고리 분류
월별 그래프
csv 다운로드
모바일 반응형

# 기술조건
프론트엔드 (HTML + CSS + JS , Bootstrap 기능)
백엔드 (PHP)
DB (MySQL)
인증(세션 기반 로그인)
